# Claude Code skills

Repo-specific procedures. Generic engineering skills (`tdd`, `code-review`, `diagnosing-bugs`, `codebase-design`, and the rest) come from the user-scoped `mattpocock/skills` plugin.

| Skill | Use for |
|---|---|
| `create-pr` | Push the task branch and open or update its pull request |
| `testing` | Run the Go and frontend checks before committing |
| `resolve-conflict` | Resolve a rebase conflict on a resumed task branch |
